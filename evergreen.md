# Evergreen fallbacks

Lives at the **root of `flaplab-dailies`**. Use these when today’s **outside** scout has no shippable art. Still search for **transparent** bird + pillar; these are concepts, not bundled files.

Prefer a live outside joke when assets exist. These keep the **assigned slot** honest instead of shipping a hollow trend.

**Do not** treat this file (or past FlapLab Dailies) as a remix menu. Skip any bullet you already shipped in the last 14 days. Never browse r/FlappyLab to pick from these.

## cat

- A **specific** viral pet photo-meme if one is circulating; else a *different* photo cutout each time (wet cat, loaf, startled stare) — vary the pillar (shampoo, rubber duck, laser pointer, cardboard box), not always yarn.
- Physics: readable flap, default-ish speed.
- Avoid shipping the same “orange loaf vs yarn in living room” package on repeat.

## fun

- Only when you still have a physics punchline worth shipping: real craft / astronaut cutout + matching world, **low-g** or **`fly`**, and say in `inspiration` what outside hook forced the fallback.
- Jet or helicopter, bomb or missile GIF pillars (tight column), terrain. **`fly` + higher speed.**
- Do not default to “generic moon astronaut vs flags” every quiet week — pick another slot’s flavour or skip.

## recognisable

Pick a face people clock in 0.3s and matching world pillars — prefer something **currently airing / patching / memeing**:

- MLP pony + crystal/castle
- Portal core + Aperture panel
- Garfield + lasagna stack
- House + cane / hospital / whiteboard (Vicodin-bottle is **drugs — skip that object**)
- COD soldier + zombie
- Terraria/Factorio character + biome machine / corrupt pillar
- KFC colonel + bucket
- Breaking Bad: face + RV or desert (not powder)
- Sopranos: Tony + gabagool / pork store

## meme

If the viral thing is a video you cannot still, drop to a visual meme format from **outside** meme culture: countryball reaction, Wojak vs Chad as bird vs pillar, exploding-brain as stacked pillars — not a remake of a known FlappyLab community game.

## country

- Country **in the news this week** as countryball, landmark or flag as pillars, flag as sky.
- If news is quiet: pick a **different** food/landmark pair than last time (do **not** default to France / baguette / Eiffel on repeat).

## political / story

- Leader face / opposition face / flag or podium photo sky — tied to a real headline when possible.
- One-sentence fable: bird wants X, pillars are the thing that stops X. New fable each time. No gore, no drugs, no nudity.
